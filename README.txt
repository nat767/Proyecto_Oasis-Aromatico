OASIS AROMATICO - INTERFACES CORREGIDAS

1. Abra esta carpeta en Visual Studio Code.
2. Instale la extension Live Server si aun no la tiene.
3. Haga clic derecho sobre index.html y seleccione Open with Live Server.
4. Registre un usuario desde la interfaz para ingresar.

Contenido:
- index.html: inicio de sesion y registro.
- pages/: dashboard, productos, inventario, proveedores, clientes, ventas, reportes y configuracion.
- css/: estilos originales y estilos del panel.
- js/: logica corregida y sincronizacion local de los modulos.
- img/: logo del proyecto.

IMPORTANTE:
Esta version guarda temporalmente los datos en localStorage. La conexion con PHP/MySQL y la autenticacion de produccion deben implementarse como siguiente etapa. No abra index.html directamente con file://; use Live Server.
